# เอกสารสำหรับนักพัฒนา Avernella (ภาษาไทย)

[English](../en/README.md)

Avernella คือโปรแกรม LINE สำหรับเดสก์ท็อป GNU/Linux ที่พัฒนาขึ้นอย่างอิสระด้วยภาษา C เอกสารชุดนี้เขียนให้โปรแกรมเมอร์และ AI ผู้ช่วยเขียนโค้ดอย่าง Claude หรือ Codex ที่เพิ่งเริ่มรู้จักรีโพนี้และต้องการเข้ามาแก้ไขหรือพัฒนาต่อ เนื้อหาอธิบายว่าแอปสร้างขึ้นอย่างไร ฟีเจอร์แต่ละอย่างทำงานอย่างไรและอยู่ตรงไหนใน `src/` รวมถึงอธิบายการทำงานของบริการ LINE เท่าที่ไคลเอนต์นี้ใช้งาน

ครั้งแรกแนะนำให้อ่านตามลำดับ หลังจากนั้นค่อยกระโดดไปหน้าที่ต้องการได้เลย

## เรื่องความถูกต้องของข้อมูล

LINE ไม่ได้เผยแพร่โปรโตคอลนี้และอาจเปลี่ยนเมื่อไรก็ได้ ทุกอย่างในเอกสารนี้ตรวจกับซอร์สโค้ดในรีโพตอนที่เขียน ถ้าเอกสารกับโค้ดไม่ตรงกัน ให้ถือโค้ดเป็นหลัก แล้วแก้เอกสารไปพร้อมกันในการเปลี่ยนแปลงเดียวกัน หมายเลขฟิลด์เขียนตามหมายเลขฟิลด์ Thrift ของ LINE เช่น "ฟิลด์ 4" ฟังก์ชันที่ระบุไว้ในแต่ละหัวข้อคือจุดที่ใช้ยืนยันรายละเอียด

ชื่อไฟล์ ฟังก์ชัน และศัพท์เทคนิคคงไว้เป็นภาษาอังกฤษเพื่อให้ค้นในโค้ดได้ตรงตัว

Avernella เป็นโปรเจกต์อิสระ LINE เป็นเครื่องหมายการค้าของ LY Corporation
