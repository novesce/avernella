## Avernella คืออะไร

Avernella คือไคลเอนต์เดสก์ท็อปแบบเนทีฟสำหรับบัญชี LINE ส่วนตัว ทำงานบน GNU/Linux เขียนด้วยภาษา C17 และวาดหน้าจอเองด้วย SDL2, Cairo และ Pango มันไม่ได้ห่อหน้าเว็บ และไม่ได้รันโค้ดของแอป LINE บน Android หรือ Windows แต่คุยกับเซิร์ฟเวอร์ของ LINE โดยตรงด้วยโปรโตคอลเดียวกับที่แอป LINE บน Windows ใช้

LINE มองแอปเดสก์ท็อปเป็น *อุปกรณ์รองที่เชื่อมกับโทรศัพท์* การลงชื่อเข้าใช้ทำได้สองแบบ คือสแกน QR code ด้วยแอป LINE บนโทรศัพท์ หรือใช้อีเมลกับรหัสผ่านแล้วยืนยันบนโทรศัพท์ จากนั้น LINE จะออกโทเค็นให้และส่งกุญแจเข้ารหัสต้นทางถึงปลายทางของบัญชีมาให้เดสก์ท็อป Avernella แสดงตัวเป็นแอปเดสก์ท็อป Windows (`DESKTOPWIN 9.7.0.3556`) และตั้งชื่ออุปกรณ์ที่เชื่อมไว้ว่า "Avernella"

แอปนี้ไม่มีส่วนเกี่ยวข้องกับ LY Corporation LINE ไม่ได้เปิดเผยเอกสารโปรโตคอล และเป็นผู้ตัดสินว่าอุปกรณ์ที่เชื่อมจะเชื่อมต่อได้หรือไม่ โปรโตคอลถูกแกะจาก LINE สำหรับ Android เวอร์ชัน 26.16.0 แล้วตรวจทานกับโปรเจกต์โอเพนซอร์สที่ทำงานร่วมกับ LINE (ดู [การมีส่วนร่วมพัฒนา](contributing.md))

### ทำอะไรได้บ้าง

สรุปสั้น ๆ คือเกือบทุกอย่างที่ผู้ใช้ LINE บนเดสก์ท็อปทำเป็นประจำ

- **ลงชื่อเข้าใช้** ด้วย QR code หรืออีเมลกับรหัสผ่าน เซสชันยังอยู่หลังปิดเปิดแอปใหม่
- **แชต**: รายการแชตพร้อมจำนวนที่ยังไม่อ่าน ประวัติแบบโหลดทีละหน้า ส่งข้อความพร้อมอีโมจิ LINE และการเมนชัน ตอบกลับ รีแอ็กชัน ยกเลิกส่ง แจ้งว่าอ่านแล้ว ประกาศ ส่งต่อ โฟลเดอร์และการปักหมุดในเครื่อง ปิดเสียงแชต ฉบับร่าง และค้นหาทั้งในแชตเดียวและข้ามแชต
- **Letter Sealing**: การเข้ารหัสต้นทางถึงปลายทางของ LINE เวอร์ชัน 1 และ 2 ทั้งแชตตัวต่อตัวและแชตกลุ่ม
- **มีเดีย**: ส่งและรับรูป วิดีโอ เสียง และไฟล์ (เข้ารหัส) เล่นวิดีโอ อัดคลิปจากกล้อง จับภาพหน้าจอ วางจากคลิปบอร์ด สติกเกอร์ อีโมจิ LINE (รวมแบบเคลื่อนไหว)
- **เนื้อหาจากบัญชีทางการ**: Flex Message, rich message (imagemap) และแอป LINE (LIFF) ในเบราว์เซอร์ภายในแอป
- **ผู้คน**: ค้นหาเพื่อนด้วย LINE ID เบอร์โทร หรือลิงก์ QR รายการโปรด ชื่อที่ตั้งเอง การซ่อนและบล็อก การ์ดโปรไฟล์ คำขอเป็นเพื่อน โปรไฟล์และรูปของตัวเอง
- **กลุ่ม**: สร้าง เปลี่ยนชื่อ เชิญ ลบสมาชิก ลิงก์และ QR สำหรับเชิญ ออกจากกลุ่ม ตอบรับและปฏิเสธคำเชิญ
- **เนื้อหาที่แชร์**: อัลบั้ม โน้ต และโพลที่โน้ตอ้างถึง
- **การโทร**: โทรเสียงและวิดีโอแบบตัวต่อตัว ปิดไมค์ เปิดปิดกล้อง แชร์หน้าจอ ดูวิดีโอเต็มจอ ตัดเสียงรบกวนด้วย RNNoise
- **การทำงานร่วมกับเดสก์ท็อป**: ไอคอนใน tray การแจ้งเตือน เสียงแบบชิปทูน NES ปุ่มลัด โหมดลดการเคลื่อนไหว ทั้ง Wayland และ X11

รายละเอียดฟีเจอร์ฝั่งผู้ใช้อยู่ใน [README ของโปรเจกต์](../../README.md) ส่วนการเปรียบเทียบกับแอป LINE บน Windows และ Mac อยู่ที่ [analysis/desktop-features.md](../../analysis/desktop-features.md)

## ศัพท์ที่จะเจอบ่อย

| คำ | ความหมาย |
| -- | -------- |
| **MID** | รหัสของ LINE สำหรับผู้ใช้ กลุ่ม หรือห้อง ยาว 33 ตัวอักษร ตัวแรกบอกชนิด ตามด้วยเลขฐานสิบหก 32 หลัก `u…` คือผู้ใช้ (รวมบัญชีทางการ) `c…` คือกลุ่ม `r…` คือห้องหลายคน แชตตัวต่อตัวระบุด้วย MID `u…` ของอีกฝ่าย ส่วน MID ของตัวเองใช้ระบุแชต *Keep Memo* |
| **RPC** | การเรียกบริการระยะไกลของ LINE เช่น `sendMessage` RPC ของ LINE คือการเรียก Apache Thrift ที่ส่งเป็น HTTP POST ดู [พื้นฐานโปรโตคอล](protocol-basics.md) |
| **หมายเลขฟิลด์ Thrift** | struct ของ Thrift ระบุฟิลด์ด้วยตัวเลข โค้ดอ่านเขียนฟิลด์ด้วยหมายเลขเสมอ ไม่ใช้ชื่อ "Message ฟิลด์ 4" หมายถึงรหัสข้อความ |
| **Operation** | บันทึกความเปลี่ยนแปลงหนึ่งครั้งในบัญชีของคุณ เช่น ได้รับข้อความ ส่งข้อความจากอุปกรณ์อื่น โปรไฟล์เปลี่ยน มีสายเรียกเข้า แต่ละอันมีหมายเลขชนิด ดู [Sync](sync.md) |
| **Revision** | ลำดับของ operation ล่าสุดที่ไคลเอนต์เห็นแล้ว การ sync คือการขอทุกอย่างที่ใหม่กว่านั้น |
| **Long poll** | คำขอ sync ที่ LINE ถือค้างไว้จนกว่าจะมีอะไรเกิดขึ้น ข่าวใหม่จึงมาถึงภายในเวลาประมาณหนึ่งรอบของเครือข่าย |
| **ลำดับคำขอ (`seq`)** | ตัวนับประจำอุปกรณ์ที่ทุก RPC ซึ่งเปลี่ยนสถานะต้องแนบไป ห้ามซ้ำเด็ดขาด ไคลเอนต์จึงจองตัวเลขลงดิสก์ก่อนเสมอ |
| **Letter Sealing** | การเข้ารหัสข้อความต้นทางถึงปลายทางของ LINE ดู [Letter Sealing](letter-sealing.md) |
| **Key chain** | ชุดกุญแจส่วนตัว Letter Sealing ของบัญชี ซึ่งโทรศัพท์เข้ารหัสส่งให้เดสก์ท็อปเครื่องใหม่ตอนลงชื่อเข้าใช้ |
| **รุ่นของกุญแจ (key generation)** | คู่กุญแจ Letter Sealing หนึ่งรุ่น ระบุด้วย key ID ข้อความเก่าจะบอกว่าถูกปิดผนึกด้วยรุ่นไหน |
| **OBS** | object storage ของ LINE ที่ `obs.line-apps.com` เป็นที่เก็บไฟล์แนบและรูปโปรไฟล์ ดู [มีเดีย](media.md) |
| **Sticon** | ชื่อที่ LINE เรียกอีโมจิ LINE คือรูปเล็ก ๆ ที่แทรกอยู่ในข้อความ |
| **Flex Message** | การ์ดที่อธิบายด้วย JSON ซึ่งบัญชีทางการส่งมา |
| **Rich message** | รูปภาพที่มีพื้นที่ให้แตะ (*imagemap* ของ LINE) ส่งมาจากบัญชีทางการเช่นกัน |
| **LIFF** | *LINE Front-end Framework*: หน้าเว็บที่ทำงานภายใน LINE พร้อมตัวตนของผู้ใช้ เช่น คูปองหรือบัตรสมาชิก ดู [LIFF](liff.md) |
| **PLANET** | ระบบส่งสัญญาณการโทรของ LINE ซึ่งส่งข้อความ protobuf ผ่าน UDP ไปยัง relay ดู [การโทร](calls.md) |
| **PDTP** | โปรโตคอลสตรีมแบบเชื่อถือได้ภายในสายของ LINE ใช้สำหรับแชร์หน้าจอ |
| **Worker** | โปรเซสที่สองของ Avernella ซึ่งถือโทเค็นและกุญแจ และทำงานเครือข่ายทั้งหมด ดู [สถาปัตยกรรม](architecture.md) |
| **`J`** | ชื่อย่อในโค้ดของ `struct json_object` จาก json-c ใช้กับข้อมูลที่มีโครงสร้างทุกชนิด |

## โครงสร้างรีโพ

```
avernella/
├── Makefile               target สำหรับ build, test, install, format และ lint
├── README.md              เอกสารสำหรับผู้ใช้
├── src/                   ซอร์ส C ทั้งหมด (ราว 49,000 บรรทัด)
│   └── render/            โมดูล Vulkan แบบเนทีฟ (เลือกได้) และ shader
├── tests/                 เทสต์ GLib แบบออฟไลน์ หนึ่งไฟล์ต่อหนึ่งโมดูล และเบนช์มาร์ก
├── data/                  ไอคอน ภาพต้อนรับ และไฟล์ .desktop
├── docs/                  เอกสารชุดนี้ (en/ และ th/)
├── analysis/              หลักฐานจากการแกะโปรโตคอล และประกาศสัญญาอนุญาตของบุคคลที่สาม
├── .clang-format          การตั้งค่าตัวจัดรูปแบบโค้ด
├── .checkpatch-typedefs   ชนิดข้อมูลจากไลบรารีสำหรับ checkpatch.pl ของเคอร์เนล
└── .github/workflows/     งานอัตโนมัติสำหรับทำแพ็กเกจ
```

`make` สร้างโปรแกรมได้สูงสุดสี่ตัวที่รากของรีโพ

| ผลลัพธ์ | คืออะไร |
| ------- | ------- |
| `avernella` | ตัวไคลเอนต์ ไฟล์เดียวกันนี้รันได้ทั้งหน้าต่าง (`avernella`) และ worker เครือข่าย (`avernella --worker`) |
| `avernella-vulkan.so` | ตัววาดภาพ Vulkan แบบเนทีฟ (เลือกได้) โหลดด้วย `dlopen` เมื่อพบไฟล์ข้าง ๆ โปรแกรมหรือใน `../lib/avernella` จะ build ก็ต่อเมื่อติดตั้งชิ้นส่วน Vulkan SDK ไว้ |
| `avernella-liff` | เบราว์เซอร์ในแอปสำหรับแอป LINE สร้างบน WPE WebKit จะ build เมื่อติดตั้ง WPE ไว้ |
| `avernella-liff-gtk` | เบราว์เซอร์ตัวเดียวกันที่สร้างบน WebKitGTK 6.0 ใช้เป็นตัวสำรอง |

### ไฟล์ซอร์สแบ่งตามหมวด

แผนผังเต็มพร้อมหน้าที่ของแต่ละไฟล์อยู่ใน [สถาปัตยกรรม](architecture.md) สำหรับเริ่มต้น

- `main.c` เริ่มทุกอย่าง และยังเป็นลูปหลักของ worker กับตัวกระจายคำขอด้วย
- `ui.c` คือลูปหลักของหน้าต่าง การเชื่อมต่อกับ worker และการจัดการคีย์บอร์ดกับเมาส์ ไฟล์ `ui_*.c` อื่น ๆ แต่ละไฟล์คือหนึ่งหน้าจอ หนึ่งแผง หรือหนึ่งบริการวาดภาพ
- `transport.c` และ `thrift.c` คือทางที่ RPC ทุกตัวเดินทางไปถึง LINE
- `pair.c`, `password_login.c` และ `state.c` คือการลงชื่อเข้าใช้และเซสชันที่บันทึกไว้
- `talk_sync.c` และ `live_sync.c` รับความเปลี่ยนแปลง
- `messaging.c`, `sealing.c`, `media*.c`, `obs_http.c`, `friends.c`, `groups.c`, `stickers.c`, `emoji.c`, `shared_content.c` และ `liff.c` แต่ละไฟล์เขียนบริการ LINE หนึ่งกลุ่ม
- `call*.c`, `camera*.c`, `screencast.c` คือการโทร

### ขนาดของไฟล์

ไฟล์ใหญ่ที่สุดคือ `ui_media.c` (ไฟล์แนบ ตัวดูรูป และหน้าจอการโทร ราว 4,400 บรรทัด) `ui_draw.c` (การวาดและจัดวาง ราว 4,000) `call.c` (เครื่องยนต์การโทร ราว 2,700) `ui.c` (ราว 2,600) และ `main.c` (ราว 2,300) โมดูลโปรโตคอลส่วนใหญ่ยาว 200 ถึง 1,300 บรรทัด

## สิ่งที่แอปตั้งใจไม่ทำ

- **ไม่มีฐานข้อมูลข้อความในเครื่อง** ประวัติ ฉบับร่าง และรายการแชตอยู่ในหน่วยความจำ และดึงจาก LINE ใหม่เมื่อต้องการ ที่เขียนลงดิสก์มีแค่เซสชัน การตั้งค่าแชต และการตั้งค่าอีกเล็กน้อย
- **ไม่มีโค้ดของ LINE** ไม่มีการลิงก์หรือรันโค้ดจากแอป LINE เบราว์เซอร์ภายในแอปรันแค่หน้า *เว็บ* ของแอป LINE เหมือนเบราว์เซอร์ในแอป LINE เอง
- **ไม่ใช่เซิร์ฟเวอร์หรือบอต** เป็นไคลเอนต์เดสก์ท็อปสำหรับบัญชีส่วนตัวของผู้ใช้เอง
- **บางฟีเจอร์ที่ LINE ไม่ได้เปิดให้ไคลเอนต์เดสก์ท็อป** เช่น สถานะออนไลน์ การแสดงว่ากำลังพิมพ์ โฟลเดอร์และหมุดที่ซิงก์ผ่านเซิร์ฟเวอร์ ดูรายการเต็มใน README
